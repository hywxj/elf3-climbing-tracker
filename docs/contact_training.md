# 0.70 米单台接触策略

当前训练目标是让 ELF3 从地面立姿走到台前，双臂扶台、双脚蹬离地面，然后把右膝送上台顶并连续承重 0.50 秒。达到这个时长就结束回合。台上起身、双脚站稳和跨越整段地形属于后续任务。项目入口及其他实验见[仓库说明](../README.md)。

训练中的 0.70 m 地形和参考姿态来自 **MuJoCo v4 动作轨迹**适配后的 50 Hz 参考包。第 2300 轮教师在仿真中成功送膝的记录提供实际受力、接触位置和电机命令。[v4 原件、预览与派生参考](experiments.md#mujoco-v4)

## 从示范到一轮 PPO

1. **离线准备示范。** 从地面行走、扶台、已经验证的蹬地送膝回合中记录关节目标、接触力和接触位置。旧第 2300 轮控制器用于录制成功送膝样本。离线拟合初始策略时，控制器先接收示范中的实测接触，再逐步改用自身预测。长训由 `student_acp_gait40_transfer.pt` 初始化，一个策略控制走近、扶台、腾空和承重的整个过程。[示范处理](../src/elf3_climbing/contact_learning.py) · [点接触初始策略](../src/elf3_climbing/contact_point_transfer.py)
2. **在仿真中执行。** 每 0.02 秒，策略读取当前与前 4 步的本体状态、当前接触状态和局部地形。从 20 × 19 个候选格点中，为左右脚、前臂、腕、膝分别预测未来 1.5 秒的接触及位置。全身控制器根据该预测输出 29 个关节相对标称姿态的目标偏移，经关节限位和目标变化速率限制后送给电机。训练入口使用仿真几何生成高度图。头部雷达已有点云回放、建图和策略输入适配，在线训练环境当前仍传入仿真几何。[策略与地形输入](../src/elf3_climbing/contact_point_actor.py) · [环境](../src/elf3_climbing/contact_tracker_env.py) · [雷达回放评估](../scripts/evaluate_lidar_replay.py)
3. **混合训练起点。** 约 50% 的重置从地面立姿开始，25% 取示范中的双脚有载状态，25% 取已验证送膝回合中四点搭稳后、双脚仍在地面的状态。每次重置都清空事件、承重计数和奖励历史。正式地面评估全部从地面开始，起点沿路线随机偏移 ±2.5 cm、横向 ±1.5 cm。另用旧示范的扶台起点单独衡量送膝能力。[训练重置](../src/elf3_climbing/contact_tracker_env.py) · [地面起点扰动](../src/elf3_climbing/contact_tracker_task.py)
4. **交替更新。** 1024 个环境各采样 32 步，每轮共 32768 个控制步。点接触策略每轮做 2 个 PPO epoch，每个 epoch 分 32 个小批次。Adam 学习率为 `8e-6`，初始动作噪声标准差为 0.025 弧度，折扣因子为 0.995，GAE λ 为 0.95，PPO 裁剪范围为 0.1。PPO 更新后对同一策略做 8 次示范学习，每次从训练集加权有放回抽 384 个样本。[PPO 与示范更新](../src/elf3_climbing/contact_runner.py) · [PPO 基础配置](../src/elf3_climbing/runner.py)

示范学习的损失单独用于反向传播。29 个关节目标的 Smooth L1 损失权重为 1（β = 0.05），是否接触的正例和已知负例各取二元交叉熵均值，权重各为 0.035。有效接触位置的三维 Smooth L1 权重为 0.12（β = 0.04），最近可见地形格的分类交叉熵权重为 0.035。PPO 的环境回报由下面 16 项组成。[示范损失](../src/elf3_climbing/contact_learning.py) · [格点监督](../src/elf3_climbing/contact_point_actor.py)

## 承重与全程成功的判据

| 事件 | 物理判据 |
|---|---|
| 交替迈步 | 摆动脚地面载荷 <5 N，对侧脚 >20 N。摆动至少 3 步、足部抬高 >2.5 cm，向前摆动 >4.5 cm 后重新承重 >20 N。首次记录落脚侧，此后由另一侧落脚才计交替。 |
| 台前四点搭稳 | 两侧上肢在台顶各支撑 >3 N，双脚地面接触各 >8 N，连续 3 步（0.06 秒）。同侧前臂与腕部在台顶的载荷可以相加，腕部非台顶接触载荷 >3 N 属于违规。 |
| 走到台前 | 腾空前形成四点支撑，搭稳前已有至少一次真实交替，双脚平均位置沿前进方向比起点至少前进 0.25 m。 |
| 蹬地与腾空 | 蹬地检查连续双侧支撑、防滑、较弱脚至少承担 8% 体重、质心上升及髋部向前上方运动。随后确认双脚从下层地面与台面卸载、离地，并通过上肢接触检查。 |
| 右膝有效承重 | 已有受支撑的腾空转移，右膝有效受力区域在台顶、膝投影在台边界内，膝载荷至少为体重的 15%（此模型约 55.73 N）。右膝接触区以外的台面载荷和左膝载荷各 ≤8 N，腕部合规，双脚离地 >1 cm 且对地各 <3 N。双臂仍可分担体重。 |
| 全程成功 | 真实地面起步，走到台前之后蹬地、腾空，再连续有效承重 25 步（0.50 秒）。承重中断就清零连续计数。局部起步可完成承重里程碑，只有地面起步能计全程成功。 |

事件通过接触求解器的实测载荷、接触区域和姿态按顺序判定。这里的 0.06 秒用于搭稳，下一节的 0.20 秒用于核验接触预测，0.50 秒用于本轮任务验收。[换步检测](../src/elf3_climbing/walk.py) · [蹬地和接触测量](../src/elf3_climbing/isaac_knee_entry.py) · [里程碑与验收](../src/elf3_climbing/contact_tracker_task.py)

## 环境奖励

### 1–6　每回合只奖励超过历史最好值的部分

每项先算一个 0 到 1 的指标。首帧建立基线，之后的得分为 `权重 × max(当前指标 − 此前最高值, 0)`。例如台前停稳从 0.4 提高到 0.7 时得 0.9 分，晃动后恢复到 0.7 时得 0 分。下表的“完成走近”指已走到台前，或本回合从局部示范起步。[物理奖励](../src/elf3_climbing/contact_tracker_env.py)

| # | 指标与权重 | 如何计算 |
|---|---|---|
| 1 | 双前臂靠近台顶 ×1 | 两前臂到有限台顶的平均距离从 0.55 m 减到零时，指标线性从 0 升至 1。至少一脚承重 >15 N。地面起步须已交替、平均前进 >0.20 m，并在最远进度 2 cm 内的台前走廊或已搭稳。 |
| 2 | 双臂在台顶受力 ×2 | 每侧载荷除以 18 N 并在 1 截断，再取左右均值。须双脚各承重 >15 N、腕部合规，走近条件与第 1 项相同。 |
| 3 | 右膝接近台面 ×4 | 四点搭稳且完成走近。用右膝到台顶的垂直距离和越出台面的水平边距合成距离，0.65 m 以外为零，靠近台顶时线性上升至 1。 |
| 4 | 台前停稳 ×3 | 已搭稳且完成走近。取第 2 项的臂支撑指标，乘双足载荷均衡系数（较弱脚载荷的两倍除以两脚总载荷），再除以 `1 + (根部线速 / 0.25 m/s)²`。 |
| 5 | 重量转移给右膝 ×4 | 已实测腾空，右膝投影在台面范围，双脚各自对地 <3 N，腕部合规。膝载荷从零增至体重的 20% 时指标从 0 增到 1，超过该值保持满分。 |
| 6 | 蹬地后撑起 ×3 | 有效蹬地后的 0.16 秒内，已完成走近且腕部合规。三个因子相乘，各自限制在 0–1。较弱臂台面载荷除以 18 N，双脚卸载比例为 `1 − 两脚地面载荷 / 体重`，质心上升速度除以 0.25 m/s。 |

### 7–16　按步、事件或一次接触计划结算

台前走廊要求两脚都在前沿外侧，且距台面左右两端各留 6 cm。下表的 `Δd` 是走廊内双脚距前沿的平均距离相对历史最好值新增的净推进米数。`u` 是机身直立系数，机身朝上方向与竖直方向的点积从 0.70 到 0.96 时线性从 0 升到 1，两端截断。`s` 是按载荷加权的承重脚滑速，单位为 m/s，控制步长 `dt = 0.02 s`。[前沿进度与换步](../src/elf3_climbing/contact_tracker_task.py) · [物理奖励](../src/elf3_climbing/contact_tracker_env.py)

| # | 奖励 | 发放条件与分值 |
|---|---|---|
| 7 | 向台前推进 | 搭稳前，至少一脚承重 >15 N 且 `s < 0.25`，给 `6 × Δd × u`。 |
| 8 | 直立、低滑移前进 | 条件同第 7 项，给 `u / (1 + (s/0.14)²) × min(Δd/0.28, dt)`，每个控制步最多 0.02 分。 |
| 9 | 有效交替换脚 | 每次 +1。真实交替落脚，位于台前走廊内、距最远进度 ≤2 cm，并比上次获奖的落脚净前进 ≥4.5 cm。 |
| 10 | 首次四点搭稳 | 满足四点搭稳判据时发一次。已完成走近给 +2，否则给 +0.25。 |
| 11 | 首次合格腾空 | 四点搭稳后检测到蹬地和双脚腾空，发一次 +3。 |
| 12 | 有效膝承重持续时间 | 腾空后每个合格承重步给 `5 × dt`（+0.10）。中断会清零验收计数，已经取得的奖励保留。 |
| 13 | 达到承重时长 | 达到要求的连续时长给 +5，并结束回合。地面与局部起点均可获得。 |
| 14 | 从地面起步全程成功 | 完成全程成功判据，额外 +10。在同一步与第 12、13 项相加。 |
| 15 | 跌倒 | 机器人根部离地 <0.43 m，给 −2 并终止。12 秒超时本身计 0 分。 |
| 16 | 预先选定的接触点与实际受力位置吻合 | 各部位连续空载至少 3 步后可提交新的目标，目标固定在世界坐标中。在 1.5 秒内连续 10 步（0.20 秒）有有效接触和压力中心，每部位每次给 `0.75 × mean(exp(−距离² / 0.10²))`，距离以米计。足、前臂、腕、膝的载荷门槛分别为 15、3、3、8 N。搭稳前的脚还须在最远进度 2 cm 内、比该脚上次位置预测获奖时净前进 ≥4.5 cm。 |

膝的 8 N 关联第 16 项的落点匹配，15% 体重启动第 12 项的有效承重计时，20% 体重对应第 5 项的转重指标满值。走路阶段的直立和防滑只有随新推进才在第 7、8 项得分。台前停稳考察根部线速度与载荷平衡，躯干原地转动的角速度不进入该项。[接触计划奖励](../src/elf3_climbing/contact_plan_reward.py) · [物理奖励与合计](../src/elf3_climbing/contact_tracker_env.py)

## 启动、复测与回放

在 `climbing_tracker/` 仓库根目录执行下面的 Bash 命令。训练需要预先配置 `isaac_sim_env` 和可用的 Isaac Lab GPU 环境。默认初始权重位于 `../output/contact_tracker/student_acp_gait40_transfer.pt`，11 个示范数据包位于 `../output/contact_examples/`。运行资产在 `$ELF3_RUNTIME_ROOT` 下，默认参考文件为该目录中的 `runs/platform_contacts_20261120_070/isaac_v4_070_surface_reference/reference.npz`。每次输出到 `$ELF3_RUNTIME_ROOT/runs/` 内的新目录。[训练脚本与数据文件名](../scripts/train_contact_tracker.sh) · [运行资产路径](../src/elf3_climbing/paths.py)

脚本默认 1024 个无头环境、3000 轮，单回合最长 12 秒。轨迹录制默认关闭，加 `--record` 才会保存复盘所需的 `.npz`。复现 10000 轮并记录评估轨迹用以下命令，训练和评估种子默认为 427 和 7241。

```bash
export ELF3_RUNTIME_ROOT="${ELF3_RUNTIME_ROOT:-$HOME/humanoid_datasheet/datasets/elf3_climbing/runtime_v1}"
bash scripts/train_contact_tracker.sh --iterations 10000 --record
```

脚本打印实际输出目录。每 100 轮做一次确定性评估，每个环境只统计本次重置后的第一个完整回合。地面报告 `ground_*.json` 的 `counts.success` 给出全程成功数，`after_walk` 记录走近后依次蹬地、腾空和触膝的回合数。`knee_seed_*.json` 记录同一策略从扶台姿态起步的结果。`best.pt` 首先按地面全程成功数选择，平分再比较各阶段到达数。`request.json` 保存实际参数，`contract.json` 保存任务、输入和实现摘要，`completion.json` 记录完成轮数。[评估与选模](../src/elf3_climbing/contact_runner.py)

复测已有模型时，指定该轮训练的目录与一个新的输出目录。以下使用已完成的 10000 轮实验。把 `--iterations 0` 改为正数会从载入的检查点再训练相应轮数。

```bash
run_dir="$ELF3_RUNTIME_ROOT/runs/contact_070_20261123_183429"
review_dir="$ELF3_RUNTIME_ROOT/runs/contact_review_$(date +%Y%m%d_%H%M%S)"
ELF3_CONTACT_WEIGHTS="$run_dir/best.pt" \
  bash scripts/train_contact_tracker.sh --iterations 0 --record --output "$review_dir"
```

评估同时生成代表回合的 `.npz`，优先选择达到更靠后里程碑的环境。下面从其中的地面回合生成原速 MP4 和间隔 0.1 秒的接触复盘图。如需检验更长承重时长，可在上一步加入 `--knee-hold-seconds 2.0`，在新的地面报告中读取 `full_course_hold_counts`。

```bash
ground_traces=("$review_dir"/ground_*.npz)
PYTHONPATH="$PWD/src${PYTHONPATH:+:$PYTHONPATH}" conda run -n isaac_sim_env \
  python scripts/review_contact_attempt.py "${ground_traces[0]}" --video "$review_dir/ground.mp4"
```

回放以 Isaac 记录的根部位姿和关节位置重建画面。默认渲染模型随 `runs/mount_070_ground_to_steady_rise_20261123/model.xml` 及同目录 `meshes/` 提供，可用 `--model` 指定对应模型。[轨迹回放](../scripts/review_contact_attempt.py)
